Проверка сервера

Если эта страница открылась, сервер успешно обработал GET-запрос и вернул статус 200 OK.

Файл стилей загружается отдельно. Это помогает проверить правильный Content-Type для CSS.

Открыть текстовый файл

Что реализовано

  • 200 OK — файл найден и отправлен.
  • 404 Not Found — файл не найден.
  • 405 Method Not Allowed — метод не поддерживается.

Учебный пример. Не используйте этот сервер как публичный production-сервер.
